# Audio Assets — Beast Arena

All `.mp3` files in this directory are **silent placeholders**.
Replace them with real audio assets before production.

## Recommended Free Sources
- **Freesound.org** — CC0 / CC-BY game SFX
- **OpenGameArt.org** — Free game audio
- **Kenney.nl** — CC0 game assets including audio
- **Mixkit.co** — Free sound effects

## Directory Structure

```
audio/
├── sfx/           # Sound effects (one-shot)

│   ├── hit_heavy.mp3
│   ├── block.mp3

    ├── confirm.mp3

```
